# SAS Customer Intelligence 360 Launchpad

Welcome to the **SAS Customer Intelligence 360 Launchpad** repository. This repository contains all supporting assets for hands-on exercises used in SAS CI 360 training courses developed and delivered by SAS Customer Intelligence Enablement.

## 📘 Overview

This repository is designed to support your learning journey with SAS CI 360. It includes sample code, connectors, configuration files, datasets, and other necessary resources to help you complete practical, real-world exercises aligned with the course content.

## 📁 Directory Structure

- **`code/`**  
  Contains scripts, sample connectors, and code for integration, export, and automation scenarios.

- **`course-specific-assets/`**  
  Organized by course and module, this folder includes assets like configuration files, Python scripts, and setup instructions.

- **`samples/`**  
  Sample datasets and JSON payloads used for testing, validation, or demonstration purposes.

- **`websites/`**  
  Static website files or web-based resources referenced in training exercises.

- **`binaries/`**  
  Executables or binary files required for specific labs or use cases.

## 🚀 Getting Started

1. **Clone or download this repository**  
   Use the green **Code** button to download as a ZIP or clone using Git.

2. **Review your course instructions**  
   Each SAS CI 360 course includes specific step-by-step guides. Refer to these for where and how to use the assets.

3. **Install required dependencies**  
   Some exercises require additional packages. Check the `requirements.txt` file within relevant folders for details.

4. **Complete exercises as instructed**  
   Use the resources in this repository alongside the course material for hands-on learning.

> **You can access the entire course catalogue at https://learn.sas.com/**
